# 入长安 · 唐姝驾到（Tang Digital Museum）

一个融合盛唐文化、非遗技艺与数字科技的静态网页项目。

本项目以“唐风女性文化 + 非遗数字化展示”为核心，通过 HTML、CSS 与 JavaScript 构建沉浸式国风数字展厅，适用于：

- GitHub Pages 静态部署
- 非遗数字化课程设计
- Web 前端学习项目
- 国风文化展示网站
- AI + 非遗融合视觉项目

---

# 项目预览

项目包含多个主题页面：

| 页面 | 功能 |
|---|---|
| index.html | 首页 |
| tangshu.html | 唐姝主题展示 |
| heritage.html | 非遗文化展示 |
| workshop.html | 非遗工坊互动 |
| future.html | 未来数字非遗展示 |
| login.html | 登录页面 |

# 本地运行方式

## 方法一：直接打开

双击：

```text
index.html
```

即可在浏览器运行。

---

## 方法二：VSCode Live Server

推荐使用：

- VSCode
- Live Server 插件

右键：

```text
Open with Live Server
```

即可获得更好的本地开发体验。
